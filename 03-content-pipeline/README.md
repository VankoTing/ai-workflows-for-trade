# 03 · 内容生产与发布流水线

> 面向公司自媒体与官网的内容自动化：从**选题**到**成稿 / 成片**，目标是日更。

## 背景

公司需要持续在自媒体平台和官网输出内容（技术文章、企业宣传视频）。选题、写作、配图、剪辑都是重复劳动，而且要维持日更节奏，人力成本很高。

## 流程设计

```
① 选题  →  ② 写稿  →  ③ 配图/排版  →  ④ 视频  →  ⑤ 发布
```

1. **选题**：AI 阅读行业公众号（如 FSG）近期文章，分析热点与空白，给出选题建议；
2. **写稿**：结合公司产品资料与行业知识，产出技术文章草稿（.docx）；
3. **配图 / 排版**：程序化生成配图与文档；
4. **视频**：根据公司资料，用**代码化视频**（React + Remotion）生成企业宣传视频；
5. **发布**：自动发布到自媒体平台与公司官网。

## 当前状态

| 环节 | 状态 |
| --- | --- |
| 选题（AI 辅助） | ✅ 已使用 |
| 文章生成（技术长文 / 选型指南） | ✅ 已产出多篇 |
| 视频生成（Remotion 代码化视频） | ✅ 已产出多支 |
| **自动发布** | 🟡 **规划中** |

> 说明：文章与视频的实际生产已在使用；**自动发布**是下一步的规划项 —— 计划接入各平台的发布接口 / 开放能力，做到"每天自动出稿并发布"。
