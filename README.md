# 外贸 AI 工作流集 · Trade AI Workflows

> 我在外贸一线用 AI 落地的一组工作流：**获客、询价单标准化、内容生产、企业知识库**。
> 目标很朴素 —— 把业务里最重复、最耗时的那几条链路，交给 AI 自动跑。

## 工作流一览

| # | 工作流 | 状态 | 一句话说明 |
| --- | --- | --- | --- |
| 01 | [自动化获客 OpenClaw](./01-leadgen-openclaw/) | ✅ 已跑通 | 海关数据 → 客户背调 → 决策人/邮箱挖掘 → 分级 → 开发信 → AI 复检 → 批量发送 |
| 02 | [询价单标准化](./02-inquiry-standardizer/) | ✅ 高频使用 | 各类询价文件 → 统一规范的结构化询价单（中英对照、横向单页） |
| 03 | [内容生产与发布](./03-content-pipeline/) | 🟡 部分自动化 | 选题 → 文章 → 视频 →（规划）自动发布到自媒体与官网 |
| 04 | [企业知识库 + 自动报价/规格书](./04-knowledge-base-rag/) | 🔵 规划中 | 公司资料入库 → RAG → 依据询价生成参考报价表与技术规格书 |

## 为什么做这些

外贸的日常里，真正创造价值的是**谈客户、拿订单**；而大量时间其实花在查客户、整理询价、追热点写文章、做视频、翻资料写报价这类**重复劳动**上。

这组工作流就是把其中最耗时的几条链路沉淀下来，做成可复用的流程 —— 让 AI 干重复的活，人只做判断和决策。

## 共同的技术特点

- **本地部署开源 Agent**（OpenClaw），业务数据不外流；
- **结构化多步提示词**：角色设定 + 分步 SOP + 输出格式约束，保证长链路输出稳定；
- **多工具链集成**：LinkedIn / Hunter.io / Apollo / Gmail MCP / 表格与文档自动化；
- **人机协同**：AI 生成 → 人工复检 → 对外交付，关键环节保留人工兜底；
- 规划中引入 **RAG**（pgvector + 本地模型）让 AI 基于自有资料回答。
