# 术语表（边做边补）

> 遇到不懂的词先记在这，做一步补一个。这也是你面试时可以拿出来讲的"知识体系"。

## 一、RAG 核心

| 术语 | 英文 | 通俗解释 | 一句话类比 |
| --- | --- | --- | --- |
| 检索增强生成 | RAG | 先查资料、再让模型回答 | 开卷考试，而不是闭卷凭记忆 |
| 切片 / 分块 | Chunking | 把长文档切成小段入库 | 把一本书拆成一张张卡片 |
| 向量 / 嵌入 | Embedding | 把文字变成一串数字，语义近的数字也近 | 给每句话算一个"意思坐标" |
| 向量数据库 | Vector DB | 存向量、支持"按意思找相似" | 图书馆的"按内容找书"系统 |
| 语义检索 | Semantic Search | 按意思找，不是按关键词 | 你说"车"，它能找到"汽车" |
| 关键词检索 | BM25 / Full-text | 按字面匹配 | Ctrl+F |
| 混合检索 | Hybrid Search | 语义 + 关键词一起用 | 两条腿走路，召回更全 |
| 重排 | Rerank | 把召回的候选再精排一次 | 初筛 50 人，复筛留下 5 人 |
| 召回 | Recall | 该找到的，有没有被找到 | 漏了就是召回低 |
| 精确率 | Precision | 找到的里面，有多少是对的 | 找了一堆无关的，精确率就低 |
| 元数据 | Metadata | 资料的属性标签（来源/密级/负责人） | 卡片背面的分类标签 |
| 上下文窗口 | Context Window | 模型一次能读的字数上限 | 一次能塞进它脑子的纸有多少 |

## 二、模型与训练（别和 RAG 搞混）

| 术语 | 通俗解释 |
| --- | --- |
| 大语言模型 LLM | 能理解和生成文字的模型（如 Qwen、GPT） |
| 参数量 7B / 14B | 模型大小，70 亿 / 140 亿参数；越大越聪明越慢 |
| 量化 Q4 / Q8 | 把模型"压缩"以省显存；Q4 约省 4 倍，效果略降 |
| 推理 Inference | 用模型生成回答的过程（我们只做这个） |
| 微调 Fine-tuning / LoRA | **训练**模型，让它学会特定风格或知识（另一条路，不是 RAG） |
| 幻觉 Hallucination | 模型一本正经地编造不存在的内容 |
| 本地部署 | 模型跑在自己电脑上，数据不出门 |

## 三、评测

| 术语 | 通俗解释 |
| --- | --- |
| 评测 Evaluation | 量化"答得准不准" |
| 黄金集 Golden Set | 人工标好的"标准问题 + 标准答案"，用来打分 |
| RAGAS | 一套常用的 RAG 评测指标（忠实度 / 相关性等） |

## 四、时间与版本（Temporal RAG）

> 起因：26 年换了供应商，新价格表必然和老价格表冲突 —— 检索分不清哪份作数。
> 设计见 `docs/versioning.md`。

| 术语 | 英文 | 通俗解释 | 一句话类比 |
| --- | --- | --- | --- |
| 时效性 | Temporal | 一条知识"什么时候有效" | 牛奶有保质期，价格表也有 |
| 版本 | Version | 同一份资料的第几版 | 合同要写明"第 X 版" |
| 文档家族 | doc_family | 逻辑上是"同一份东西"的所有版本 | 一本书的初版和再版属同一家族 |
| 生效 / 失效日期 | effective_from / to | 有效期是一个**区间** | 会员卡的起止日期 |
| 当前版本 | active / current | 在"今天"这个时点有效的那一版 | 现在生效的那份合同 |
| 时间旅行 | as-of | 按指定日期查询 | "去年这个时候卖多少钱？" |
| 质量衰减 | Decay | 资料随时间推移可信度下降 | 不是错，而是"可能已过时" |
| 版本冲突 | Conflict | 同家族多份同时有效、内容不一致 | 两份价格表都在，谁作数？ |
| 内容指纹 | Fingerprint | 哈希值，判断两份文件内容是否相同 | 文件的"指纹"，用来查重 |
| 知识血缘 | Provenance | 一条回答引用了哪一版、什么日期 | 追责时要能查到"依据是哪份" |

## 五、我们的技术栈

| 组件 | 选型 | 为什么 |
| --- | --- | --- |
| 模型运行时 | **Ollama** | 一条命令跑本地模型，省心 |
| 生成模型 | **Qwen2.5-7B**（Q4） | 中文强，8G 显存能跑 |
| 向量模型 | **bge-m3** | 中文/多语言检索效果好 |
| 向量库（阶段一） | **Chroma** | pip 装完即用，无需服务端；支持元数据过滤 |
| 向量库（阶段三） | **pgvector** | 上多用户/权限后换成 PostgreSQL + pgvector |
| 解析 | pypdf / python-docx / openpyxl + OCR | 覆盖 PDF / Word / Excel / 扫描件 |
