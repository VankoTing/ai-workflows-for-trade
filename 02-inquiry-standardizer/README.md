# 02 · 询价单标准化工作流

> 把格式各异、来源不同的询价内容（客户邮件、Excel、PDF、截图），统一转成**固定规范的结构化询价单**。

## 背景

外贸每天收到大量询价，格式五花八门：有的在邮件正文里、有的是扫描件、有的 Excel 列名都不一致。人工整理又慢、又容易漏，而且整理格式每次都不一样，转给客户或供应商时还得再返工。

## 方案

**不去适配每一种输入格式，而是固定输出格式。**

设计一套固定的输出规范，作为提示词约束交给 AI —— 无论输入多乱，产出永远是同一套结构：

- 单个 Sheet、**横向布局**（每个产品一行，参数横向展开为列）；
- **中英对照**：同一单元格内中文在上、英文在下；
- **数量单独成列**，不做合并单元格；
- **参数单独成列**；型号等编码参数要在独立列里给出其**解码含义**，而不是只保留裸编码；
- 单页紧凑排版，不出现大片留白。

## 关键提示词（模板）

```
请把我提供的询价内容整理成一份结构化询价单，严格遵守以下规范：
1. 输出为单个 Sheet，横向布局：每个产品一行，其参数横向展开为列；
2. 中英对照：同一单元格内中文在上、英文在下；
3. 数量单独成列，不做合并单元格；
4. 型号等编码参数需在独立列中给出其解码含义（不要只保留裸编码）；
5. 禁止跨文档合并数据、禁止引入外部推断，所有数据必须来自我提供的文件；
6. 输出为紧凑的单页排版，不出现大片留白。
```

## 效果

- 从"每份询价手动整理 30–60 分钟"变成"发过去等结果"，且**格式完全一致**，可直接转发；
- 累计处理数十份询价（蝶阀 / 截止阀 / 球阀 / 控制阀 / MTO 物料清单等）。

## 实现说明

- 表格由脚本统一生成（openpyxl），保证格式稳定、可批量；
- 提示词里明确"数据只来自输入文件"，避免模型自行补全导致出错。
